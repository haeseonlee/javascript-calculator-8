# javascript-calculator-precourse

1. 구분자와 양수로 구성된 문자열을 입력받는다.
   - 입력값에 음수가 존재하면 예외가 발생한다.
   - 정해진 구분자가 아니거나, 잘못된 구분자 입력시 예외가 발생한다.
2. 입력값이 `기본 구분자`를 포함하는 문자열인지, `커스텀 구분자`를 포함하는 문자열인지 확인한다.
   - 기본 구분자인 경우 쉼표(,)와 콜론(:)을 기준으로 분리한다.
   - 커스텀 구분자인 경우 "//"와 "\n" 사이에 존재하는 문자를 추출하여 구분자로 지정한 후 문자열을 분리한다.
3. 분리된 문자열을 배열에 저장한다.
4. 배열에 저장된 문자열을 숫자로 변환한다.
5. 숫자로 변환된 값들을 모두 더하여 반환한다.
6. 결과값을 출력한다.
